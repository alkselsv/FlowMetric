# 🎯 Video Analytics: Zero-Shot Detection & Multi-Object Tracking

[![Python](https://img.shields.io/badge/Python-3.10%2B-blue.svg)](https://www.python.org/)
[![PyTorch](https://img.shields.io/badge/PyTorch-2.x-EE4C2C.svg)](https://pytorch.org/)
[![BoxMOT](https://img.shields.io/badge/BoxMOT-25.x-orange.svg)](https://github.com/mikel-brostrom/boxmot)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Продвинутый конвейер видеоаналитики для детекции и многообъектного трекинга (MOT) в реальном времени. Проект объединяет мощь **zero-shot детекции** (Grounding DINO) с современными алгоритмами трекинга (**BoxMOT**), обеспечивая высокую точность при отслеживании объектов по текстовому описанию без необходимости дообучения модели.

---

 🌟 Ключевые особенности

- 🧠 **Zero-Shot Детекция:** Использование модели `IDEA-Research/grounding-dino` для поиска объектов по текстовому промпту (по умолчанию: люди и столы).
- 🏃‍♂️ **Мульти-трекинг:** Поддержка 9+ алгоритмов через **BoxMOT 25.x** (BotSort, ByteTrack, StrongSort, DeepOcSort, HybridSort и др.).
- 🛡️ **Умный Fallback:** Если BoxMOT не инициализируется, скрипт автоматически переключается на `supervision.ByteTrack` или встроенный `SimpleIoUTracker`, гарантируя работу пайплайна.
- ⚡ **Оптимизация производительности:** Поддержка CUDA, смешанной точности (FP16/AMP), динамического ресайза кадров и пропуска кадров (`--frame-stride`).
- 📦 **Беспроблемная установка:** Скрипт `requirements.sh` автоматически разрешает сложные конфликты зависимостей (включая фиксацию `gdown==4.7.3` для корректной загрузки ReID-моделей).

🚀 Подробная установка

Проект использует изолированное Conda-окружение для гарантии совместимости всех библиотек.

 Шаг 1: Клонирование репозитория
``` bash
git clone https://github.com/nofriendsatall/video_analytics.git
cd video_analytics
conda activate dino-boxmot
```

Архитектура работы скрипта:
Инициализация: Загрузка модели Grounding DINO на выбранное устройство (CUDA/CPU) и инициализация выбранного трекера.
Цикл обработки: Чтение кадра. Если включен --frame-stride, кадры пропускаются для экономии ресурсов GPU.
Детекция: Кадр масштабируется (до --max-size), конвертируется в RGB и подается в модель с текстовым промптом "person . table . desk . dining table .".
Постобработка: Координаты боксов масштабируются обратно к оригинальному размеру, применяется NMS для удаления дубликатов, а метки классов нормализуются (например, "dining table" превращается в "table").
Трекинг: Отфильтрованные боксы передаются в трекер, который сопоставляет их с предыдущими кадрами и присваивает уникальные track_id.
Вывод: Отрисовка bounding box'ов с ID и классом, наложение счетчика FPS, запись в файл или вывод в окно OpenCV.


| Аргумент | По умолчанию | Описание |
| :--- | :--- | :--- |
| `--source` | `"0"` | Источник видео: путь к файлу (`video.mp4`), RTSP-поток (`rtsp://...`) или индекс веб-камеры (`0`). |
| `--model-id` | `IDEA-Research/grounding-dino-base` | Идентификатор модели Hugging Face. Используйте `IDEA-Research/grounding-dino-tiny` для ускорения на слабых GPU. |
| `--device` | `"auto"` | Устройство для вычислений: `auto` (CUDA, если есть, иначе CPU), `cuda`, `cpu`. |
| `--tracker` | `"auto"` | Алгоритм трекинга. Доступные: `botsort`, `bytetrack`, `ocsort`, `deepocsort`, `strongsort`, `hybridsort`, `occluboost`, `boosttrack`, `sfsort`, `simple`. `auto` пытается запустить BotSort, затем ByteTrack. |
| `--box-threshold` | `0.30` | Минимальная уверенность для bounding box от модели детекции. |
| `--text-threshold` | `0.25` | Минимальная уверенность совпадения текстового промпта с объектом. |
| `--nms-iou` | `0.50` | Порог Intersection over Union (IoU) для подавления дублирующихся боксов (NMS). |
| `--max-size` | `1280` | Максимальный размер длинной стороны кадра перед подачей в модель. Уменьшение этого значения значительно ускоряет инференс. |
| `--fp16` | `False` | Включить смешанную точность (Automatic Mixed Precision). Работает только на CUDA, дает прирост скорости и экономит видеопамять. |
| `--frame-stride` | `1` | Обрабатывать каждый N-й кадр. Например, `2` означает обработку каждого второго кадра (полезно для видео с высоким FPS). |
| `--max-age` | `30` | Сколько кадров трекер будет "помнить" исчезнувший объект, прежде чем удалить его трек (параметр `track_buffer`). |
| `--iou-threshold` | `0.25` | Порог IoU для встроенного `SimpleIoUTracker` (используется как крайний fallback). |
| `--reid-weights` | `osnet_x1_0_msmt17.pt` | Путь к файлу весов модели ReID. Обязателен для трекеров с префиксом "Deep" или "Strong". |
| `--output` | `""` | Путь для сохранения результирующего видео (например, `output.mp4`). Если не указан, видео не сохраняется. |
| `--no-display` | `False` | Отключить отображение окна `cv2.imshow`. Обязательно для запуска на удаленных серверах без GUI. |

Пример использования

``` bash
python temp.py --source 0 \
               --model-id IDEA-Research/grounding-dino-tiny \
               --device cuda \
               --fp16 \
               --max-size 800 \
               --tracker bytetrack
```
